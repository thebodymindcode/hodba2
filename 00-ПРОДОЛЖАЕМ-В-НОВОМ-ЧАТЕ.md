## Грабли, на которые уже наступили (не повторять)
- Правка HTML регулярками по большим блокам рвёт разметку: один раз продуктовый блок уехал в начало страницы, другой раз пропал абзац, третий раз сломалась скобка в CSS и кнопка съехала влево. Править только точными строками и сразу проверять балансы.
